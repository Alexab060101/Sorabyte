# Soinea

Sitio web de Andrea Agudelo (Soinea) · soins corporels à Fribourg.

- HTML estático, sin build step.
- Deploy: Vercel (importar este repo).
- Dominio: soinea.ch
- Idioma: francés.

## Estructura

- `index.html` · home
- `podologie.html` · `laser.html` · `massages.html` · `esthetique.html` · servicios
- `reservas.html` · `contact.html` · reserva y contacto
- `styles.css` · `motion.js`

## Desarrollo local

Servir la carpeta con cualquier static server:

```bash
python -m http.server 8000
```

Abrir http://localhost:8000
